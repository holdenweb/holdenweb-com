## How This Site Works

##### Assuming, that is, that it does ...

Little people inside the server read your input, encode it on an abacus,
and zip through the computations with mighty speed.

No seriously, though, this site is maintained with a little utility called
qs (for "quick site"). This lets you include pages written in either HTML
(if you are a traditional web author, or need specific content tags) or
Markdown - a simple language that can nevertheless render reasonably
complex layouts, including mathematics, which seems appropriate for a
radio club's web site. The source code for qs can be found on Github.
